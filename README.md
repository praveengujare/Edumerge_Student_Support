# EduSupport – Student Support & Ticket Management System

EduSupport is a full-stack Student Support & Ticket Management System developed as part of the Edumerge Solutions Product Engineering Assignment.

The system allows students to raise support requests and enables support staff to manage, prioritize, assign, track, and resolve those requests.

---

## Problem Statement

Students may need support for issues related to:

- Fees
- Attendance
- ID Cards
- Documents and certificates
- Academic matters
- Technical issues
- Hostel and transport
- Other administrative requests

EduSupport provides a centralized system to manage these requests through a structured ticket workflow.

---

## Features

### Student Features

- Student registration
- Student login
- Create support tickets
- Select support category
- Select ticket priority
- View submitted tickets
- View ticket details
- Track ticket status
- View ticket activity history

### Staff Features

- View all support tickets
- Assign tickets to staff
- Update ticket status
- Prioritize tickets
- Track ticket ownership
- View ticket history
- View SLA due time

### Management Dashboard

The dashboard provides visibility into:

- Total tickets
- Open tickets
- In-progress tickets
- Pending tickets
- Resolved tickets
- Closed tickets
- Overdue tickets
- Ticket priority distribution
